# Bunch of Scammers

We build **ShadyUI**: framework-agnostic components for professionally untrustworthy interfaces.

ShadyUI recreates the visual language of suspicious reward generators, fake download pages, impossible giveaways, and other wonderfully questionable corners of the web—while keeping the implementation accessible, transparent, and harmless.

## Projects

- [ShadyUI Core](https://github.com/bunchofscammers/shady-ui) — framework-agnostic Web Components
- [ShadyUI React](https://github.com/bunchofscammers/shady-react) — official React integration
- [ShadyUI Svelte](https://github.com/bunchofscammers/shady-svelte) — official Svelte integration
- [Documentation](https://bunchofscammers.github.io/shady-docs/) — guides, architecture, and showcase
